# Controller RJ-45 Pinout

| Color       | Nombre (es)       | Función / Notas                                   |
| ----------- | ----------------- | ------------------------------------------------- |
| 🔵 Azul     | Joystick Y        | Señal analógica del eje Y del joystick            |
| 🟡 Amarillo | Joystick X        | Señal analógica del eje X del joystick            |
| 🟠 Naranja  | Bit de conexión   | Línea digital para handshake / estado de conexión |
| 🟢 Verde    | LED               | Alimentación / señal para LED indicador           |
| 🟣 Violeta  | Potenciómetro     | Entrada analógica de potenciómetro                |
| ⚫ Negro    | Botón Down        | Pulsador para acción "bajar"                      |
| ⚪ Blanco   | Botón Switch Mode | Pulsador para cambiar modo                        |
| ◻️ Gris     | Botón Up          | Pulsador para acción "subir"                      |

Notas:

- Verifica con un multímetro/continuidad antes de conectar si no estás seguro del cableado.
