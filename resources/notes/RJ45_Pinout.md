# Controller RJ-45 Pinout

| Color       | Nombre (es)       | Función / Notas                                   | Pin PONCHO |
| ----------- | ----------------- | ------------------------------------------------- | ---------- |
| 🔵 Azul     | Joystick Y        | Señal analógica del eje Y del joystick            | VRY        |
| 🟡 Amarillo | Joystick X        | Señal analógica del eje X del joystick            | VRX        |
| 🟠 Naranja  | Bit de conexión   | Línea digital para handshake / estado de conexión | ON         |
| 🟢 Verde    | LED               | Alimentación / señal para LED indicador           | L          |
| 🟣 Violeta  | Potenciómetro     | Entrada analógica de potenciómetro                | POT        |
| ⚫ Negro    | Botón Down        | Pulsador para acción "bajar"                      | DWN(S)     |
| ⚪ Blanco   | Botón Switch Mode | Pulsador para cambiar modo                        | MD         |
| ◻️ Gris     | Botón Up          | Pulsador para acción "subir"                      | UP         |

Notas:

- Verifica con un multímetro/continuidad antes de conectar si no estás seguro del cableado.
